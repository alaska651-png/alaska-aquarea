# Changelog

## 1.1.0 — 2026-11-25

Aquarea Clima is now the primary published dashboard: full schematic/circuits, PDC controls, energy/history and COP analysis. Main sources promoted to aquarea-clima/, HACS entry example corrected to custom:aquarea-clima-host, complete source ZIP and setup guide added. Coordinator retained as a linked component. Installation-specific state remains excluded. No changes to the running installation.

## 1.0.0 — 2026-11-25

Initial public release: coordinator, weekly profiles, floor average mode, persistent manual room timers, HACS frontend, companion source snapshot, generic examples and automated checks. Firmware remains in `heishamon-wt32-eth01-cz`.

HACS distributes the frontend. Backend configuration and physical commissioning are separate.
